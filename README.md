# AI Nutrition Coach

AI栄養コーチ

## 概要

日々の食事記録をもとに栄養摂取状況を可視化し、次に摂る食事を提案することで食生活の改善を支援するアプリケーションです。

現在はVer.1を開発中です。

## 開発背景

栄養管理では、摂取したカロリーや栄養素を記録・確認するだけでなく、「不足している栄養素を補うために、次に何を食べればよいのか」まで分かることが食生活の改善につながると考え、本アプリの開発を開始しました。

単なる食事記録にとどまらず、ユーザーの栄養摂取状況をもとに具体的な次の行動を提案できるサービスを目指しています。

## 主な機能

### 実装済み

* 食品データの登録・取得・更新・削除（CRUD）
* 食事記録の登録・取得
* 食品データと食事記録の連携
* 摂取量に応じたカロリー・PFC（タンパク質・脂質・炭水化物）の計算
* 1日単位の栄養摂取量集計

### 今後実装予定

* ユーザー認証
* プロフィール管理
* 食事記録機能の拡充
* ユーザーごとの目標栄養量の算出
* 栄養摂取状況に基づく食事提案
* Flutterによるフロントエンド
* AIを活用した個別の食事提案

## データベース

現在、以下のテーブルを実装しています。

* `users`
* `profiles`
* `foods`
* `meal_records`

外部キーを用いてユーザー、プロフィール、食品、食事記録を関連付けています。

## API

現在、FastAPIを使用して食品・食事記録に関するREST APIを開発しています。

主な実装済みAPI：

* `GET /foods`
* `GET /foods/{food_id}`
* `POST /foods`
* `PATCH /foods/{food_id}`
* `DELETE /foods/{food_id}`
* `POST /meal-records`
* `GET /meal-records`
* `GET /daily-summary`
